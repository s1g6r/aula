# Deploying Aula to Render

Aula runs on Render's free tier: one Node web service and one Postgres database. Both are defined in `render.yaml` at the root of the repo (a "Blueprint"), so Render sets everything up from that file. You only paste your Featherless key once.

Total time: about 15 minutes, plus waiting for DNS.

---

## 1. Push the code to GitHub

Render deploys from GitHub, so the latest code needs to be there:

```
cd ~/terminalais/aula
git push -u origin main
```

## 2. Create the services on Render

1. Go to **https://render.com** and click **Get Started**. Choose **GitHub** to sign in, so there's no new password.
2. When Render asks for GitHub access, choose **Only select repositories** and pick **s1g6r/aula**.
3. In the Render dashboard click **New +**, then **Blueprint**.
4. Pick the **s1g6r/aula** repository. Render finds `render.yaml` and lists what it will create:
   - **aula**, a web service (Free)
   - **aula-db**, a PostgreSQL database (Free)
5. It asks for one value, **AI_API_KEY**. Paste your Featherless key (the same one as in `.env.local`).
6. Click **Apply** (or **Deploy Blueprint**).

The first build takes about 5 minutes. Watch it under **aula**, then **Logs**. When it says "Your service is live", open the URL at the top of the page. It looks like `https://aula-xxxx.onrender.com`. Add `/api/health` to the end, and you should see `{"ok":true,...}`.

**Send me that `onrender.com` URL.** I'll run the end-to-end tests against it: live captions through Render's network, a Wi-Fi drop, translations, and signals.

## 3. Point aulaapp.xyz at Render

**In Render:**

1. Open the **aula** service, then **Settings**, then **Custom Domains**.
2. Click **Add Custom Domain** and enter `aulaapp.xyz`. Render also adds `www.aulaapp.xyz` and redirects it to the main domain.
3. Render shows the DNS records it expects. Keep that page open.

**Where your domain is managed** (the registrar dashboard you used to claim `aulaapp.xyz` through Gen.xyz), open the DNS settings for `aulaapp.xyz` and:

| Type | Host / Name | Value | Notes |
|---|---|---|---|
| **A** | `@` (the root) | `216.24.57.1` | Render's load balancer. If your provider offers ALIAS or ANAME for the root, you can use that instead, pointing to your `onrender.com` host. |
| **CNAME** | `www` | `aula-xxxx.onrender.com` | Use your actual Render host from step 2. |

- **Delete any AAAA records** for `@` or `www`. Render uses IPv4 only, and leftover AAAA records break verification.
- Delete any "parking page" or "URL redirect" records the registrar added by default.

Back in Render, click **Verify** next to each domain. DNS can take from a few minutes to a few hours. Once verified, Render issues the HTTPS certificate automatically.

## 4. Keep it awake (so judges never wait)

Free Render services go to sleep after 15 minutes without visitors, and waking up takes about a minute. A free uptime monitor visits every 5 minutes so it never sleeps. One service running all month is about 744 hours, which fits in Render's 750 free hours.

1. Go to **https://uptimerobot.com** and create a free account.
2. **Add New Monitor**: type **HTTP(s)**, name **Aula**, URL `https://aulaapp.xyz/api/health`, interval **5 minutes**.
3. Save. The monitor turning green means the site is up.

Until the custom domain works, use your `onrender.com` URL there instead.

## 5. Things to know

- **The free database is deleted 30 days after it's created,** with a 14-day grace period to upgrade. Created around Sep 27, it lasts until about Oct 27 and is deleted around Nov 10. The landing page and Demo Replay don't use the database, so they keep working even after that. Live lessons would need a new database.
- **The Featherless key is valid for one month.** After it expires, live lessons still work but show English captions with highlighted terms. The Demo Replay isn't affected.
- **Every push to `main` redeploys automatically** (`autoDeploy: true`). Database migrations run when the new version starts (`npm run start:prod`).
- **Secrets stay out of git.** `AI_API_KEY` lives only in Render's dashboard, and `AUTH_SECRET` is generated by Render.
- **Privacy clean-up runs hourly on the server.** Lessons older than 30 days (24 hours for guest lessons) are deleted with everything under them.
